# DeepSeek Harness Desktop v0.1.0

首个完整开源版本，将官方 DeepSeek Harness `0.1.0-rc.6` 封装为 Windows
Electron 桌面应用。

## 下载选择

- `DeepSeek-Harness-Desktop-Setup-0.1.0-x64.exe`：标准安装版；
- `DeepSeek-Harness-Desktop-Portable-0.1.0-x64.exe`：便携单文件；
- `DeepSeek-Harness-Desktop-Source-0.1.0.zip`：对应源码；
- `SHA256SUMS.txt`：以上文件的 SHA-256。

## 功能

- Electron 原生标题栏替换为自绘标题栏；
- 自绘最小化、最大化/还原和关闭按钮；
- 使用 Harness 官方包自带的鲸鱼图标；
- 内置锁定版本的 Node.js 和完整 Harness 运行依赖；
- 本地随机回环端口、隔离的 `WebContentsView` 和受限 IPC；
- 一键准备、构建、许可证生成与 GitHub Release 工作流。

## 注意

这是非官方社区封装，不提供模型额度，也不绕过 API 鉴权。安装包没有商业代码
签名，因此 Windows 可能显示“未知发布者”。DeepSeek Harness 本身仍处于
Developer Preview。
