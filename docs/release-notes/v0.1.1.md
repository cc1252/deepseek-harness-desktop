# DeepSeek Harness Desktop v0.1.1

将内置的官方 DeepSeek Harness 从 `0.1.0-rc.6` 更新到 `0.1.7-rc.1`，包含上游新增的 Web 终端、会话归档、插件管理、文件预览和 Agent Team 面板等功能。桌面壳继续使用 Electron `43.4.0` 和 Node.js `24.19.0`。

## 升级说明

- 应用数据仍保存在 `%APPDATA%\deepseek-harness-desktop\harness-home`。
- 上游在这些版本间升级了会话日志格式。旧日志会被保留并迁移，但升级后的会话不能由旧版 Harness 读取。需要回退时，请使用升级前的数据备份。
- 这是非官方社区封装，仍不提供模型额度或绕过 API 鉴权。
